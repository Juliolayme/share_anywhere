# Claude Design handoff

UI source of truth exported from Claude Design (project "Share Anywhere Product Design"). File names and contents are kept exactly as exported. Do not edit these files; re-import from Claude Design to update them.

| File | Contents |
|---|---|
| `Design System.dc.html` | Design tokens and components |
| `Screen Map.dc.html` | Screen IDs and flows |
| `i18n-strings.json` | EN/VI UI strings |
| `Handoff Checklist.dc.html` | Handoff checklist |
| `Brand.dc.html` | Brand guidelines |
| `Logo.dc.html` | Logo |
| `Web App.dc.html` | Web app screens (PC and mobile browsers) |
| `Android App.dc.html` | Android app screens |
| `iOS App.dc.html` | iOS app screens |
| `support.js` | Runtime script the `.dc.html` prototypes load |
